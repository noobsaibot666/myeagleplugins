# Eagle custom plugins

Install these archives from Eagle using the plugin installer, or extract the
archive and install the folder manually if the Eagle version does not show the
installer option.

Included builds:

- `Pinterest Search Importer` — v2.4.5
- `Are.na Search Importer` — v0.3.2
- `Frame Set Search Importer` — v0.1.0

These plugins are JavaScript/Eagle web plugins and do not contain macOS-only
native binaries. The same archives are suitable for Windows and macOS; no
separate Windows build is required.

The archives are deterministic and were validated by the project packaging
scripts. SHA-256 checksums are in `SHA256SUMS.txt`.
